# 009 – Text Slots

Status: todo · Depends on: 005

## What

Add Text Slots for captions and titles.

## Acceptance criteria

- [ ] Text Slots can be added, moved, resized and deleted, like Photo Slots.
- [ ] The text is edited in place.
- [ ] Styling options:
  - font family, from the system fonts
  - size
  - colour
  - bold and italic
  - left, centre or right alignment
- [ ] Text that doesn't fit keeps its size, and the Slot shows an overflow warning.
- [ ] The text content belongs to the Page. The style is stored on the Slot, so a Layout can carry it as a default (see 010).
