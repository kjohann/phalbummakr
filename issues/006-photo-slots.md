# 006 – Photo Slots and placing Photos

Status: todo · Depends on: 003, 005

## What

Add rectangular Photo Slots to a Page and fill them by dragging Photos from the grid. This creates Placements.

## Acceptance criteria

- [ ] Photo Slots can be added, moved, resized and deleted on a Page.
- [ ] Slot geometry is stored as fractions of the Page.
- [ ] Dragging a Photo from the grid onto a Photo Slot creates a Placement. Dropping onto an occupied Slot replaces its Photo.
- [ ] A new Placement fills the Slot with a centred Crop.
- [ ] The editor draws Placements from cached **previews** (about 2048 px on the long edge, generated by Rust), never from originals.
- [ ] A Placement stores the Photo's path relative to the Library root.
