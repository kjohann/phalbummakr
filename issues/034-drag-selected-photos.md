# 034 – Drag Selected Photos to a Folder

Status: todo · Type: feature · Depends on: 028, 033

## What

Dragging moves only the dragged Photo (026). With several Selected Photos, dragging one of them should move all of them, following the same rule as right-click in the [028 addendum](028-addendum.md). Promoted from the backlog ("Drag several Photos to a Folder").

Comes from real use (inbox, Sort mode).

## Acceptance criteria

- [ ] Dragging a Selected Photo from the grid, or from the Comparison, to a Folder tile or breadcrumb moves every Selected Photo.
- [ ] Dragging a Photo that isn't selected moves only that Photo.
- [ ] The drag image shows how many Photos are being moved when there's more than one.
- [ ] A Folder already holding every dragged Photo doesn't accept the drop.
